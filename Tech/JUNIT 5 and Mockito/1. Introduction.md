# 🧪 1. Introduction to Testing

Software testing ensures that your code behaves correctly under different conditions.

## 🎯 Why Testing?
- Catch bugs early
- Ensure code reliability
- Enable safe refactoring
- Improve design quality
- Required for production-grade systems

---

# 🧩 2. Types of Testing

## 🔹 2.1 Unit Testing
- Tests **individual components (methods/classes)**
- Fast, isolated
- No external dependencies (DB, API, Kafka)

### Example
int add(int a, int b) { return a + b; }

Test:
assertEquals(5, add(2, 3));

---

## 🔹 2.2 Integration Testing
- Tests **interaction between components**
- Involves DB, Kafka, APIs, etc.

### Example
- Service + Repository + DB working together

---

## 🔹 2.3 Functional Testing
- Tests **complete feature behavior**
- Focus: business requirements

### Example
- "User can create account successfully"

---

## 🔹 2.4 End-to-End (E2E) Testing
- Tests **entire system flow**
- UI → Backend → DB

---

## 🔹 2.5 Other Types

| Type | Description |
|------|------------|
| Smoke Testing | Basic system health |
| Regression Testing | Ensure old features still work |
| Performance Testing | Load/stress testing |
| Security Testing | Auth, vulnerabilities |
