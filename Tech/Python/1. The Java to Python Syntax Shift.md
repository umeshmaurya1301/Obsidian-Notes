# 1. The Java to Python Syntax Shift

> [!info] Goal
> Map the Java syntax you already know onto Python. Same concepts, fewer keystrokes, no braces, no semicolons. This is muscle-memory retraining, not new theory.
>
> Part of [[Tech/Python/Roadmap|Python Roadmap]] → prev: [[0. Foundations & Mental Model]]

---

## 1. Indentation IS the syntax

No braces, no semicolons. **Indentation (4 spaces) defines blocks** — it's not cosmetic, it's the grammar. A `:` opens a block.

```python
def greet(name):
    if name:
        print(f"Hi {name}")   # inside if
    print("done")             # inside function
```

```java
// Java
void greet(String name) {
    if (name != null) { System.out.println("Hi " + name); }
    System.out.println("done");
}
```

> [!warning] Mixing tabs and spaces raises `IndentationError`/`TabError`. Pick spaces and never look back.

## 2. Conditionals — `if` / `elif` / `else`

```python
if score >= 90:
    grade = "A"
elif score >= 80:      # 'elif', not 'else if'
    grade = "B"
else:
    grade = "C"
```

- No parentheses needed around the condition.
- `elif` replaces Java's `else if`.
- **No `switch`** historically — use `if/elif` chains or, in 3.10+, structural pattern matching (`match`/`case`, covered in Phase 7).

---

## 3. Loops — `for` and `while`

Python's `for` is a **for-each** over an iterable; there is no C-style `for(i=0; i<n; i++)`.

```python
for item in items:          # for-each
    print(item)

for i in range(5):          # 0,1,2,3,4
    print(i)

for i in range(2, 10, 2):   # start, stop, step → 2,4,6,8
    ...

for idx, val in enumerate(items):   # index + value
    print(idx, val)

while n > 0:
    n -= 1                  # no n-- ; use -= 1
```

> [!tip] Loop `else`
> A loop can have an `else` that runs **only if the loop finished without `break`** — handy for search loops.
> ```python
> for x in data:
>     if x == target:
>         break
> else:
>     print("not found")   # runs only if no break
> ```

`break` and `continue` work exactly like Java.

## 4. Variables & Dynamic Typing

No type declarations — the variable takes the type of whatever you assign.

```python
x = 10        # int
x = "now str" # totally legal — rebound to a different type
```

```java
int x = 10;   // Java: type fixed at declaration
```

- Type is attached to the **object**, not the variable name.
- Optional **type hints** add readability/tooling without enforcing at runtime: `x: int = 10` (Phase 7).

### `None` vs `null`

`None` is Python's `null` — a real singleton object.

```python
result = None
if result is None:     # use 'is', not '==', for None
    ...
```

---

## 5. `a is b` vs `a == b` (identity vs equality)

| Operator | Checks | Java analog |
|---|---|---|
| `a == b` | **value** equality (calls `__eq__`) | `.equals()` |
| `a is b` | **identity** (same object in memory) | `a == b` (on references) |

```python
a = [1, 2]; b = [1, 2]
a == b   # True  (same contents)
a is b   # False (different objects)
```

Use `is` only for singletons: `None`, `True`, `False`.

## 6. Mutable vs Immutable

This drives behavior all over Python (function args, dict keys, default args).

| Immutable | Mutable |
|---|---|
| `int`, `float`, `bool` | `list` |
| `str` | `dict` |
| `tuple` | `set` |
| `frozenset` | (custom objects) |

```python
s = "hello"
s[0] = "H"        # ❌ TypeError — strings are immutable
s = s.capitalize() # ✅ make a new string instead
```

> [!tip] Only **immutable** (hashable) objects can be dict keys or set members. A `tuple` can be a key; a `list` cannot.

## 7. Operators worth noting

```python
7 / 2     # 3.5   → true division (always float)
7 // 2    # 3     → floor division
2 ** 10   # 1024  → exponent (no Math.pow needed)
7 % 3     # 1     → modulo
```

- **Logical:** `and`, `or`, `not` (words, not `&&` / `||` / `!`).
- **Ternary:** `value_if_true if condition else value_if_false`
  ```python
  status = "pass" if score >= 50 else "fail"
  ```
- **Chained comparisons** (no Java equivalent):
  ```python
  if 0 < x < 100:   # instead of x > 0 && x < 100
      ...
  ```
- **Walrus `:=`** — assign inside an expression (3.8+):
  ```python
  while (line := input()) != "quit":
      print(line)
  ```

## 8. Truthiness

Any object can be tested in a boolean context. **Falsy** values:

```
False, None, 0, 0.0, "" (empty str), [] {} () set()  (empty collections)
```

Everything else is **truthy**.

```python
items = []
if not items:          # Pythonic "is empty" check
    print("empty")

name = user_input or "Anonymous"   # short-circuit default
```

- `and`/`or` **short-circuit** and return one of the operands (not a strict bool) — that's why `a or default` works as a fallback.

## 9. Strings

### f-strings (string interpolation)

```python
name, n = "Umesh", 3
f"Hi {name}, you have {n} msgs"
f"{3.14159:.2f}"     # '3.14' — format spec
f"{x=}"              # 'x=10' — debug form
```

Beats Java's `String.format` / concatenation for readability.

### Slicing `[start:stop:step]`

`stop` is **exclusive**. Negative indices count from the end.

```python
s = "abcdef"
s[0]      # 'a'
s[-1]     # 'f'  (last)
s[1:4]    # 'bcd'
s[:3]     # 'abc'
s[::-1]   # 'fedcba'  → reverse idiom
```

> [!tip] Same slicing syntax works on **lists and tuples** too — learn it once.

### Common methods

```python
"  hi ".strip()            # 'hi'
"a,b,c".split(",")         # ['a','b','c']
",".join(["a","b","c"])    # 'a,b,c'
"Hello".replace("l","L")   # 'HeLLo'
"Hi".lower() / .upper()
"abc".startswith("ab")     # True
"x" in "text"              # True  (substring check)
```

Strings are immutable, so every method returns a **new** string.

## 10. Input / Output

```python
print("a", "b", sep="-", end="!\n")   # a-b!
name = input("Name: ")                # always returns a str
age = int(input("Age: "))             # cast explicitly
```

## Java → Python cheat sheet

| Java | Python |
|---|---|
| `else if` | `elif` |
| `for (int i=0;i<n;i++)` | `for i in range(n):` |
| `x == null` | `x is None` |
| `a.equals(b)` | `a == b` |
| `a == b` (refs) | `a is b` |
| `&&` `\|\|` `!` | `and` `or` `not` |
| `cond ? a : b` | `a if cond else b` |
| `Math.pow(2,10)` | `2 ** 10` |
| `String.format(...)` | f-strings |
| `i++` / `i--` | `i += 1` / `i -= 1` |
| `{ }` blocks | indentation + `:` |

---

## Key Takeaways (revision)

- Indentation is the syntax; `:` opens every block.
- `for` is for-each; use `range()` / `enumerate()` for indices.
- `None` + `is`; value-equality + `a == b`; identity + `a is b`.
- Immutability decides what can be a dict key and how args behave.
- Lean on Pythonic idioms early: truthiness checks, `or`-defaults, slicing, f-strings, chained comparisons.
