## ⭐ Priority: Must Know (⭐⭐⭐⭐⭐)

These are the topics that get asked, in almost every interview.

**1. JDBC basics** → [[1. JDBC Fundamentals]], [[16. Spring Boot Integration]]
Why JDBC exists · driver · connection · `PreparedStatement` · `ResultSet` · transactions · connection pool (HikariCP)

**2. ORM + JPA + Hibernate** → [[2. ORM Basics]], [[3. JPA]], [[4. Hibernate]], [[5. Persistence Context]], [[8. Dirty Checking and Flush]]
ORM · JPA · Hibernate · EntityManager · Session · Persistence Context · Dirty Checking · First-Level Cache

**3. Entity mapping** → [[6. Entity Mapping]]
`@Entity` · `@Table` · `@Id` · `@GeneratedValue` · `@Column` · `@Transient` · `@Enumerated` · `@Embedded`
*Used every single day.*

**4. Relationships** → [[7. Relationships]]
`@OneToOne` · `@OneToMany` · `@ManyToOne` · `@ManyToMany` · `mappedBy` · `@JoinColumn` · cascade · `orphanRemoval`
*Probably the most asked topic. Expect questions here.*

**5. Fetching** → [[9. Fetching]]
Lazy · Eager · proxy · N+1 · fetch join
*Asked constantly.*

**6. Transactions** → [[10. Transactions]]
`@Transactional` · propagation (at least `REQUIRED`, `REQUIRES_NEW`) · isolation levels · rollback · ACID

**7. Spring Data JPA** → [[13. Spring Data JPA]]
`JpaRepository` · query methods · `@Query` · `Pageable` · `Sort` · Specifications
*Almost every company uses it.*

**8. Performance** → [[14. Performance Tuning]]
N+1 · batch insert · batch update · `LazyInitializationException` · read-only transactions · when to use native SQL
*This is where experienced developers stand out.*

## 🔸 Skip for Now (⭐⭐)

Don't spend much time here unless you hit them at work — but they're written up in [[17. Hibernate Internals]] and [[15. Advanced Hibernate]] if you want the depth:

Bytecode enhancement · Hibernate event listeners · action queue · multi-tenancy · Envers · custom types · reflection internals · proxy generation internals · cache providers · `persistence.xml`

> [!note] Worth breaking the rule for
> Read the **action queue** and **proxy generation** sections of [[17. Hibernate Internals]] anyway. They're short, and they're the *reason* behind half the ⭐⭐⭐⭐⭐ behaviours — why entities can't be `final`, why delete runs after insert, why `LazyInitializationException` exists. Knowing the mechanism is what separates a recited answer from an explained one.

## 🧠 The mental model to carry into the room

```text
HTTP Request
       │
       ▼
Controller          ← entities or DTOs?
       │
       ▼
Service
       │
       ▼
@Transactional      ← is the boundary right? any network calls inside?
       │
       ▼
Spring Data JPA
       │
       ▼
EntityManager
       │
       ▼
Persistence Context ← managed or detached? how many entities?
       │
       ▼
Hibernate           ← N+1? fetching efficiently?
       │
       ▼
HikariCP            ← enough connections? held too long?
       │
       ▼
JDBC Driver
       │
       ▼
Database            ← indexed? locks? deadlocks?
```

If you can walk an interviewer down this stack and say something intelligent at every layer, you're prepared.
