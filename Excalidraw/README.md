# 🎨 Excalidraw — Drawings

Hand-drawn diagrams, sketches and visual explanations live here. Excalidraw is a freehand whiteboard built into Obsidian — perfect for the kind of bit-slot / sliding-window / system-design visuals these notes already use as ASCII art.

> [!info] First time?
> Open [[Welcome Drawing]] and choose **More options (⋮) → Excalidraw** if it shows as text. If the starter ever looks odd, just make a fresh one (command palette → **Excalidraw: Create new drawing**) — nothing else in the vault depends on this file.

---

## ✏️ Create a drawing
- Ribbon: click the **Excalidraw** pencil icon, **or**
- Command palette (`Ctrl+P`) → **Excalidraw: Create new drawing**.
- Save new drawings in this `Excalidraw/` folder to keep them together (set the default folder in *Settings → Excalidraw → Saving*).

## 🔗 Embed into a note
Drop a drawing straight into any note like an image:

```
![[My Diagram]]
```

It renders as a picture in Reading view and stays fully editable — double-click to jump back into the canvas. Resize with `![[My Diagram|400]]`.

## 💡 Good uses here
- **DSA patterns** — sliding window, two-pointers, bit slots, tree/graph traversals (replace the ASCII diagrams in the `LT_*` notes with crisp visuals).
- **System design** — HLD/LLD boxes-and-arrows for the Tech roadmap topics.
- **Kafka / Concurrency** — producer→broker→consumer flows, thread lifecycles.

> [!tip] Pair with the Vault Map
> For *linking* notes visually use the core **[[Vault Map.canvas|Canvas]]** (boxes that open notes). For *freehand drawing* use Excalidraw. They complement each other.
