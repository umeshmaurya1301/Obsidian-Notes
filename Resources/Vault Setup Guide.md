## 🔒 How to install safely

All picks below are **open-source** and published in Obsidian's **official Community Plugins store**, which the Obsidian team screens. You stay in control — *you* click install.

1. *Settings → Community plugins* → **Turn on community plugins** (if first time).
2. **Browse** → search the plugin name → **Install** → **Enable**.
3. Restart isn't needed; tweak each in its own settings tab.

> [!warning] Trust rule of thumb
> Only install from the in-app **Browse** list. Don't paste plugin files from random websites. Everything here is widely used (hundreds of thousands of installs) and actively maintained.

---

## ⭐ Essential — unlocks the makeover

- **Style Settings** — *author: mgmeyers*
  Adds a UI panel to tweak my CSS variables (accent colour, card width, corner radius) with sliders/colour-pickers — no editing CSS. My snippets are already annotated for it, so a **Cool & Focused** section appears automatically. → *Settings → Style Settings*.
- **Iconize** *(search "Iconize", id `obsidian-icon-folder`)* — *author: FlorianWoelki*
  Set an icon on any folder/note in the file explorer. Instantly makes the sidebar beautiful. Suggested: 🧮 DSA, ☕ Java, 🐍 Python, 🧵 Concurrency, 🟧 Kafka, 🪙 Finance, 🎯 Events.

## 👍 Recommended

- **Minimal Theme Settings** — *author: kepano (Obsidian's CEO)*
  Official companion to your **Minimal** theme. Unlocks colour schemes, fonts, block width, and a native `cards` layout. Pairs cleanly with these snippets.
- **Homepage** — *author: mirnovov*
  Auto-opens a chosen note on startup. Point it at **`Home`** so the dashboard is your front door. → *Settings → Homepage → Homepage = `Home`*.

## 🧩 Optional

- **Recent Files** — *author: tgrosinger* — a sidebar list of recently opened notes (complements Home's "Continue where you left off").
- **Banners** — *author: noatpad* — header/cover images on notes & dashboards for extra polish (purely cosmetic).
- **Table Editor** *(already installed, currently off)* — enable it for spreadsheet-style editing of the many Markdown tables. Turn on in *Community plugins*.

## 🎨 After installing

> [!example] Quick wins
> 1. **Homepage** → set to `Home`.
> 2. **Iconize** → right-click folders → *Change icon*.
> 3. **Style Settings** → open the *Cool & Focused* section; nudge accent or card width to taste.
> 4. Open **[[Vault Map.canvas]]** and the **[[Home]]** dashboard in Reading view to see cards, stats and styled tables.

> [!tip] Everything degrades gracefully
> The CSS works with or without these plugins — they just add UI convenience. Disable any snippet anytime in *Settings → Appearance → CSS snippets*.
